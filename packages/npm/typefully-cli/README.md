# @skastr0/typefully-cli

JSON-first CLI for Typefully content publishing and analytics workflows.

```bash
npx -y @skastr0/typefully-cli --help
bunx @skastr0/typefully-cli --help
pnpm dlx @skastr0/typefully-cli --help
```

This package installs the `typefully` command through a Node launcher and optional platform packages containing prebuilt Bun standalone binaries.

Supported platforms:

- macOS arm64/x64
- Linux arm64/x64

See the repository README for command reference and API key setup.
